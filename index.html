Ajuda da operação

Consulta rápida

Fluxo recomendado

  1. Cadastre as caixas disponíveis na aba Caixas.
  2. Cadastre os produtos com dimensões, peso e código de barras.
  3. Na Home, leia os códigos ou informe as quantidades manualmente.
  4. Marque as regras de cada produto e clique em Calcular caixas.
  5. Confira a lista, a ordem de colocação e a visualização 3D.

Leitura por código

  • Use o campo Código de barras para registrar produtos com scanner.
  • Quantidade por leitura multiplica a próxima leitura feita e depois volta para 1.
  • Na aba Código de barras, imprima comandos de quantidade e use 1 quantidade para corrigir a última leitura.
  • Leia 9999999999999 para finalizar o pedido e calcular automaticamente.
  • Leia 9999999999998 para iniciar um novo pedido com a leitura limpa.
  • Leia 9999999999997 duas vezes seguidas para limpar o pedido atual.
  • Leia 9999999999996 para desfazer a última leitura.
  • Se o código não existir, use Cadastrar produto para criar o item.
  • Ctrl+Z desfaz a última leitura registrada.

Regras dos produtos

Pode girar Permite testar orientacoes retas e diagonais do produto dentro da caixa.
Em pé Mantém o produto na orientação vertical durante o empacotamento.
Empilhável Indica que outros itens podem ser colocados acima desse produto.
Frágil Prioriza cuidado de empilhamento e destaca o item no resultado.

Resultado e 3D

Como conferir

  • Caixas necessárias mostra a quantidade final de volumes.
  • Volume ocupado indica o aproveitamento médio das caixas.
  • Produtos sem caixa aparecem quando nenhuma caixa atende dimensões, peso ou restrições.
  • A ordem numerada mostra a sequência sugerida de colocação.

Visualização 3D

  • Arraste para girar a caixa.
  • Use a roda do mouse para apróximar ou afastar.
  • Clique em um produto da legenda para destacar no 3D e nas vistas.
  • Use Tela cheia para ampliar a conferência.

Histórico, exportação e backup

Histórico

  • Os últimos cálculos ficam salvos na Home.
  • Use Reabrir para carregar um cálculo e revisar a separação.
  • Filtros por data e busca ajudam a localizar pedidos anteriores.

Arquivos

  • CSV baixa a lista do resultado para planilha.
  • Relatório gera uma versão de conferência por caixa.
  • PDF abre a impressão do resultado atual.
  • Backup exporta ou importa caixas e produtos cadastrados.

Códigos de comando

Como usar

  1. Imprima estes códigos e deixe as etiquetas próximas da área de separação.
  2. Na Home, leia normalmente todos os produtos do pedido.
  3. Leia 2, 3, 4 ou 5 quantidades antes do produto quando a próxima leitura deve somar várias unidades.
  4. Leia 1 quantidade depois de um produto para ajustar a última leitura daquele produto para 1 unidade.
  5. Depois que o produto for lido, a quantidade volta automaticamente para 1.
  6. Quando o último produto for lido, leia Finalizar pedido para calcular as caixas automaticamente.
  7. Use Desfazer leitura para remover a última leitura feita sem usar teclado.
  8. Para apagar a separação atual, leia Limpar pedido duas vezes seguidas.
  9. Depois da conferência, leia Novo pedido para limpar a tela e preparar a próxima separação.
